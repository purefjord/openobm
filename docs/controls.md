# Controls

These bindings apply to the Rust `play` frontend. See the README for its current
development-data requirements.

| Key | Action |
|---|---|
| Arrow keys | Move, navigate menus, or scroll |
| Enter or Space | Attack, confirm a selection, or dismiss dialogue |
| Q | Left soft key: back/cancel; opens the pause menu during gameplay |
| W | Right soft key: confirm/action; opens the action/item menu during gameplay |
| 0–9 | Phone keypad inputs |
| 7 | Quick-use the assigned healing potion, by default |
| 9 | Quick-use the assigned magicka potion, by default |
| 3 | Toggle weapon/attack mode, by default |
| Escape | Exit the application |

Quick-key assignments can be changed in the game's Custom Controls menu.
Soft-key actions depend on the current screen; follow the labels displayed there.

To use a poison cure, open the action/item menu with W, move to Items, select
Remove Poison, and confirm. A healing potion restores health but does not remove
the poison effect.
